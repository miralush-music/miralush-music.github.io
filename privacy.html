Privacy Policy

Last updated: November 24, 2026

Mira Lush Music Tools ("the tools") are personal tools used only by the owner of the YouTube channels Mira Lush, Red Jazz Corner and Plymaker to manage their own channels.

What the tools access

The tools use the YouTube Data API (YouTube API Services) with the channel owner's permission to upload the owner's own videos, set titles, descriptions, thumbnails and playlists, read basic information about the owner's own channel and videos, and add translated titles and descriptions.

How data is stored

The Google sign-in token is saved only on the channel owner's own computer. No data is sent to any server run by the tools, sold, or shared with anyone.

YouTube and Google

By using the tools you are also bound by the YouTube Terms of Service, and Google handles data under the Google Privacy Policy.

Removing access

Access can be removed at any time at myaccount.google.com/permissions. Deleting the token file on the computer also removes the tools' access.
